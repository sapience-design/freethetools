# 5. AGPL-3.0 for code, trademarks kept by Sapience Design

Date: 2026-09-27 · Status: accepted

## Context

The PDF engine (Ghostscript) and the Python CLI library (PyMuPDF) are AGPL-3.0. Sapience Design wants the project to stay open and to be clearly a Sapience initiative, without forks passing themselves off as it.

## Decision

License the code under AGPL-3.0-only. Keep "Free the Tools" and the Sapience name and logo as trademarks outside the licence (TRADEMARKS.md). Accept contributions under the Developer Certificate of Origin (sign-off), with no contributor licence agreement.

## Consequences

- Anyone running a modified copy as a public service must publish their source. The site links its source from every page, meeting AGPL section 13.
- Contributors keep their copyright; the project can't be relicensed without their agreement.
- Forks must rebrand.
